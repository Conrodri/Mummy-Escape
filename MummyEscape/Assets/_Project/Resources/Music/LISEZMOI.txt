Musiques du jeu

Deux thèmes, avec un fondu enchaîné entre eux :
- menu.(mp3|ogg|wav) : les menus (tout écran avec la barre de navigation) ;
- game.(mp3|ogg|wav) : en jeu (tombeau, duels, écrans de résultat).
Sans "game", le thème du menu joue partout ; sans "menu", le premier fichier du dossier, sinon la
boucle synthétisée (drone grave + vent). Conseil : boucle propre (fin qui s'enchaîne au début),
1 à 3 min, import Unity "Load Type: Streaming" pour économiser la mémoire.
